## Sobre este livro

Em 2006, Pablo Marçal foi a uma entrevista de emprego de bermuda, tênis de skatista e sem apresentação preparada. Todos tentaram convencê-lo a desistir. Ele não desistiu — converteu o medo em energia e foi aprovado.

**Este livro faz o mesmo com Angular.**

Cada capítulo de *Antimedo* de Pablo Marçal — o medo, a alienação, as crenças limitantes, o ciclo que paralisa — vira um conceito Angular real que você roda, testa e entende. Não é motivação com código de enfeite. É código de verdade com a motivação necessária para não abandonar quando ficar difícil.

::: cuidado O que este livro não promete
Este livro **não vai te tornar Angular expert em um dia**. Angular é um framework robusto com uma curva de aprendizado real. O que ele promete é: você vai **enfrentar cada conceito com a mentalidade certa**, sem se paralisar pelo que não sabe ainda.
:::

## Para quem é

Para quem **já conhece HTML, CSS e JavaScript básico** e quer aprender Angular a sério. Se você nunca programou, comece por um curso de JavaScript primeiro.

## O mapa do livro

| Bloco | Capítulos | O que aparece |
|---|---|---|
| **Bloco I — A Anatomia do Medo** | 1 a 5 | CLI, componentes, change detection, lifecycle hooks, formulários reativos |
| **Bloco II — Quebrando o Ciclo** | 6 a 10 | RxJS, lazy loading, injeção de dependência, standalone, pipes |
| **Bloco III — A Transformação** | 11 a 13 | Guards, interceptors, error handling, Signals |
| **Bloco IV — A Invencibilidade** | 14 a 19 | Router, NgRx, diretivas, testes, SSR, build de produção |
| **Laboratório** | Lab 1 | App Antimedo completo — tudo integrado |

## Como estudar

1. **Leia a analogia do Antimedo primeiro**: ela não é enfeite — ela ancora o conceito.
2. **Digite o código, não copie**: o aprendizado está nos seus dedos.
3. **Faça os exercícios antes de ver a resposta**: mesmo que erre, o esforço vale.
4. **Use os flashcards para revisão**: revise os do capítulo anterior antes de avançar.

::: dica Pré-requisitos rápidos
Se você já tem Node.js instalado, instale o CLI:

```bash
npm install -g @angular/cli
```

Verifique a instalação:

```bash
ng version
```

```saida
Angular CLI: 17.x.x
Node: 20.x.x
```

Você está pronto.
:::

::: resumo O mantra deste livro
**O medo de um conceito Angular tem intimidade com o conceito que você nasceu para dominar.**

Cada vez que você sente que "isso é difícil demais", é sinal de que aquele conceito é exatamente o que você precisa aprender. Não fuja — enfrente um capítulo por vez.
:::
