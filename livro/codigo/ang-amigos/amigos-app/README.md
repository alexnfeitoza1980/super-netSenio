# Amigos UI Showcase — Design System com Angular 19 & CDK

Aplicação de referência do **Livro 3: Como Fazer Amigos e Influenciar Pessoas em Angular**.

## 🚀 Tecnologias Empregadas
- **Angular 19+** (Standalone Components, Signals, Computed, Signal Queries)
- **Angular CDK** (`@angular/cdk/a11y`, `@angular/cdk/overlay`, `@angular/cdk/scrolling`, `@angular/cdk/drag-drop`, `@angular/cdk/testing`)
- **Reactive Forms & ControlValueAccessor**
- **Testes com Component Harnesses**

## 💻 Como Rodar
```bash
npm ci
npm start
npm run test:ci
npm run build
```
Abra `http://localhost:4200`. Os testes usam Jasmine/Karma e Component Harnesses.
