# Antimedo em Angular (Livro 1 da Coleção Aprenda Angular)

Livro interativo baseado na obra **Antimedo** de Pablo Marçal, adaptada para o ensino da arquitetura e desenvolvimento frontend com **Angular 17+**.

## O Que Este Livro Ensina

- **Bloco I — A Anatomia do Medo (Caps 1 a 5):** Do primeiro `ng new` ao ciclo de vida e formulários reativos.
- **Bloco II — Quebrando o Ciclo (Caps 6 a 10):** RxJS (filtro de sinal vs ruído), lazy loading, injeção de dependência e componentes standalone.
- **Bloco III — A Transformação (Caps 11 a 13):** Route guards, HTTP interceptors, resiliência a falhas com `retry` e reatividade pura com **Angular Signals**.
- **Bloco IV — A Invencibilidade (Caps 14 a 19):** Navegação com Router, state management com NgRx, diretivas, testes unitários, SSR e build de produção.
- **Laboratório Prático (Lab 1):** Construção do sistema **Antimedo Hub** passo a passo.

## Como Ler

Abra `index.html` em qualquer navegador (funciona 100% offline via protocolo `file:///`).

Para reconstruir o livro após editar o conteúdo em `content/`:

```bash
python build.py
```

## Código-Fonte do Aplicativo

A pasta `codigo/antimedo-app/` contém a implementação funcional completa da aplicação desenvolvida no Laboratório 1, incluindo testes unitários.
