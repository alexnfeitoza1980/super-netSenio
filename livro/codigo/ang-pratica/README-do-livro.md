# Angular na Prática — Biblioteca Viva

Livro prático para aprender Angular 22 construindo, passo a passo, uma biblioteca digital acessível. O texto, o código e os diagramas são originais. A aplicação de exemplo usa Angular e TypeScript; não depende de outro framework de interface.

## Abrir e estudar

Abra `index.html` para ler offline. Cada capítulo apresenta objetivos, explicações, exemplos, exercícios, quiz e cartões de revisão. Os diagramas SVG ficam em `img/`.

## Executar o projeto

Requer Node.js 22.12 ou mais recente:

```bash
cd codigo
npm ci
npm start
npm run test:ci
npm run build
```

O aplicativo **Biblioteca Viva** é uma demonstração de front-end: o catálogo inicial é local e favoritos/progresso são guardados no `localStorage` do navegador. O livro explica como substituir a fonte local por uma API real, sem fingir que o protótipo já tem autenticação ou backend.

## Privacidade e convivência

O projeto não envia dados pessoais. O conteúdo explica como comunicar problemas e revisar código com clareza e respeito. Exercícios de reflexão são opcionais e não são terapia nem aconselhamento profissional.
